# 0001. Dos recorridos, un portafolio

El inicio presenta aplicaciones, integraciones y automatización. El perfil profesional tiene versiones en inglés y español. La página de servicios explica qué problemas resuelvo y enlaza al contacto para proyectos. GitHub enlaza directamente a ambos recorridos.

La rama parte de main. Los seis casos publicados, su fuente de datos y sus URL se conservan. La dirección visual adopta la paleta y la tipografía del rediseño previo.

El sitio, el perfil profesional y el CV describen el trabajo actual como desarrollo remoto en el sector salud. El contenido público usa enero de 2026 y agosto de 2026 como fechas del empleo y la graduación. El inglés se describe por capacidad, sin equivalencia certificada.
